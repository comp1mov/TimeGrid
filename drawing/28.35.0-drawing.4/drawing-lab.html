What to test

Start in Single: change Width and Stabilizer, draw slow curves and fast diagonals. Then draw across cells, try TPL, erase part of a line, Undo/Redo, then Save → Open. Grid and Single are views of the same frame drawings. BG has separate Grid/Single surfaces. Wheel or two fingers zoom; choose Pan to move. Frame buttons and Play select the active frame. In Grid, the frame number is highlighted.

This lab uses 96 generated test frames. Drawing Lab has its own version; this release updates only the lab. Each grid gesture keeps one continuous geometry shared by its affected frames. Width uses frame pixels, so it looks smaller in Grid. It does not replace the existing TimeGrid drawing tools, import old raster drawings, or save a full media project. Files from Drawing Lab drawing.2 open with their original contours. New files use schema 3 and need drawing.4 or newer. Spray particles and soft dabs are saved as geometry. Pen pressure takes priority over speed. Soft edge accumulates opacity as dabs overlap. PNG exports the current view at 1536 × 1296 (Grid) or 2048 × 1152 (Single), from saved geometry. Undo history is session-only, up to 100 gestures with a 16 MB geometry estimate budget (the latest gesture is always retained). No uploads or cloud processing. Browser closing requires Save first.
