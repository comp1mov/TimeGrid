What to test

Draw across cells, try TPL, erase part of a line, Undo/Redo, then Save → Open. Grid and Single are views of the same frame drawings. BG has separate Grid/Single surfaces. Wheel or two fingers zoom; choose Pan to move. Frame buttons and Play select the active frame. In Grid, the frame number is highlighted.

This lab uses 96 generated test frames. It does not replace the existing TimeGrid drawing tools, import old raster drawings, or save a full media project. PNG exports the current view at 1536 × 1296 (Grid) or 2048 × 1152 (Single), from saved contours. Undo history is session-only, up to 100 gestures with a 16 MB geometry estimate budget (the latest gesture is always retained). No uploads or cloud processing. Browser closing requires Save first.

Benchmark runs in a separate temporary document, then downloads timings from your device. It does not change your drawing. Physical pen and phone testing is still needed. perfect-freehand MIT license
