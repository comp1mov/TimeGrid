27 октября 2026. Ветка codex/drawing-engine. [Тестовая сборка](https://comp1mov.github.io/TimeGrid/drawing/28.35.0-drawing.9/index.html). Stable28.34 и опубликованный Lab.8 этим выпуском не изменяются.

Неперехваченных ошибок браузера нет.

[Дополнительный прогон](extra-results.json):128 реально импортированных портретных PNG, рисунок в нижней части кадра 127, точный PNG после Save/Open и сброса кэша; импорт созданного MP4,128 сэмплов; touch emulation390/320 сDPR2, Save открывает слоты и L1 доступен после S1. ## Скорость и память

Один новый прогон, desktop mouse,1280×860,DPR1,96 портретных кадров. Один штрих проходит через центры всех 96 кадров.191 отрисовка: median5.0ms,p95 9.4ms,max19.4ms.2 вызова getBoundingClientRect за сам проход, после построения карты геометрии. Кэш 96tiles,3852288bytes при бюджете 24MiB. Overlay1280×812, два viewport canvas примерно 7.9MiB RGBA. JSON57826 символов включает предшествующие источники и данные сеанса. Это не чистый A/B с 28.34 и не измерение полного heap или физического телефона. Исторические результаты Lab.8 не переименованы в .9.

## Ограничения и приёмка

- Файл рисунка schema7 хранит геометрию, fixed stamps/Fill и адреса кадров, а не видео и не весь проект. Идентичность файла: name/size/lastModified, для видео дополнительно sample time/frame number. Это не content hash. При несовпадении источника старые данные сохраняются, но не переносятся на случайные новые кадры. Переименованный файл не считается тем же источником.
- BG Grid/Single раздельны. Экспорт включает внешние границы при Export BG ON, OFF возвращает обычный размер. Границы после ластика консервативны. PNG с полностью прозрачным фоном сохраняет прежнюю политику исключения BG. PNG-sequence отдельный BG ограничен 2048 по длинной стороне; отсутствие постоянного большого canvas не отменяет памяти финального экспорта.
- Fill действует на нарисованный замкнутый контур активного слоя. Временная маска до 4MiPixels. Шаг 0.5logicalpx, для полного квадратного кадра 1px; BG1px и окно 2048px. Уже залитую область перекрашивать через Undo и повторную Fill. Фото/видео не задают границы.
- Кэш растеризуется в масштабе вывода до 16×, бюджет 24MiB. Полный proxy/source-decoding workflow не реализовывался. TPL Apply сохраняет сгруппированные операции, включая erase.
- Слоты, три быстрых цвета и настройки кисти живут в сеансе. Не выдаём файл рисунка за полноценный project.
- Проверить физические phone/tablet/pen: ощущения кисти, двухпальцевый zoom, pressure/ластик, панель в портрете/альбоме; свой материал, Long/1F/Onion, BG, Spacing, PNG/MP4. Затем адресные исправления drawing-ветки. Перенос в main после авторской приёмки.
