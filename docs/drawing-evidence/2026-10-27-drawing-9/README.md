## Ограничения и приёмка

- Файл рисунка schema7 хранит геометрию, fixed stamps/Fill и адреса кадров, а не видео и не весь проект. Идентичность файла: name/size/lastModified, для видео дополнительно sample time/frame number. Это не content hash. При несовпадении источника старые данные сохраняются, но не переносятся на случайные новые кадры. Переименованный файл не считается тем же источником.
- BG Grid/Single раздельны. Экспорт включает внешние границы при ExportBGON, OFF возвращает обычный размер. Границы после ластика консервативны. PNG с полностью прозрачным фоном сохраняет прежнюю политику исключения BG. PNG-sequence отдельный BG ограничен2048по длинной стороне; отсутствие постоянного большогоcanvas не отменяет памяти финальногоэкспорта.
- Fill действует на нарисованный замкнутый контур активного слоя. Временная маска до4MiPixels. Шаг0.5logicalpx, для полного квадратного кадра1px; BG1px и окно2048px. Уже залитую область перекрашивать через Undo и повторную Fill. Фото/видео не задают границы.
- Кэш растеризуется в масштабе вывода до16×, бюджет24MiB. Полный proxy/source-decoding workflow не реализовывался. TPL Apply сохраняет сгруппированные операции, включая erase.
- Слоты, три быстрых цвета и настройки кисти живут в сеансе. Не выдаём файл рисунка за полноценный project.
- Проверить физические phone/tablet/pen: ощущения кисти, двухпальцевый zoom, pressure/ластик, панель в портрете/альбоме; свой материал, Long/1F/Onion, BG, Spacing, PNG/MP4. Затем адресные исправления drawing-ветки. Перенос вmain после авторской приёмки.
