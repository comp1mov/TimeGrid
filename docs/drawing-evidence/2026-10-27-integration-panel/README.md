# Панель интеграции, 27 октября 2026

Это локальные DOM-макеты в обычном TimeGrid drawing.2, а не опубликованная сборка и не второй Drawing Lab. Источник приложения18be376. Временный браузер использовал настоящий HTML/CSS приложения; grid sample синтетический, проверку импорта/рисования/экспорта эти картинки не доказывают.

- [Desktop](1280-panel.png): принят автором. Четыре строки, свободный drag.
- [Mobile390](390-panel.png) и [320](320-panel.png): первый вариант192px **отклонён** как слишком большой. Автор согласовал убрать постоянный рядслотов на телефоне и раскрывать его черезSave. Новый mobile screenshot последует после этой правки.
- [Тёмный список с Fill](390-tools.png).
- [Полный Draw](1280-draw-settings.png): расположение параметров без conditional hiding. Общая оптимизация меню отложена.
- [Исходные размеры и браузер](layout.json): Edge156, layout emulation, mouse-driven pointer drag в touch-capable viewport. Не тест физического телефона или пера.
